# Project Requirements

## Overview

Social Media, Y (formerly Chatter) needs a web frontend. The backend
already exists at [dummyjson.com/docs/posts](https://dummyjson.com/docs/posts).

## Tech stack

React, TypeScript, Bun, React Router.

## Features

- Browse a feed of posts
- Search posts
- Open a post and see its comments
- Create a post
- Delete a post

## Deployment

Must run as a Docker container.
