# Y.com

**Features:** browse a feed, search posts, open a post to read its
comments, create a post, delete a post. Data comes from
[dummyjson.com](https://dummyjson.com/docs/posts), a free fake API — posts
you create or delete aren't actually saved anywhere.

## Getting started

Requires [Bun](https://bun.com/docs/installation) (no Node.js needed).

```bash
bun install
bun dev
```

Opens at `http://localhost:3000`.
